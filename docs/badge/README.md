# Badges

Two SVGs, served from `https://opentechevents.org/badge/`. Put one in your README, your site
footer or your community page: it is the cheapest way for the next organiser to find out this
exists, and the only piece of outreach that keeps working while nobody is looking at it.

| Badge | Use it if | File |
| --- | --- | --- |
| ![OTE: publishes a feed](ote-feed.svg) | You publish an OTE feed | `ote-feed.svg` |
| ![OTE: supporter](ote-supporter.svg) | You back the spec, consume it, or plan to adopt it | `ote-supporter.svg` |

Markdown:

```markdown
[![OTE: publishes a feed](https://opentechevents.org/badge/ote-feed.svg)](https://opentechevents.org)
[![OTE: supporter](https://opentechevents.org/badge/ote-supporter.svg)](https://opentechevents.org#support)
```

HTML:

```html
<a href="https://opentechevents.org"><img src="https://opentechevents.org/badge/ote-feed.svg" alt="OTE: publishes a feed"></a>
```

Nobody checks whether you earned it. If you wear the feed badge, please point it at a feed that
actually resolves — a badge that lies is worse than no badge.

Hand-written SVG, no service behind it: the badge keeps rendering if shields.io is down, and it
never phones home about who is reading your README. If you need another wording (a translated
one, or "consumes OTE"), open an issue — the file is 20 lines.
